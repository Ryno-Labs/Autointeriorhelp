# AutoInteriorHelp.com — GitHub Pages Demo

Static, no-build website. Upload the contents of this folder to the root of a GitHub repository and enable **Settings → Pages → Deploy from branch**.

## Main pages
1. `index.html`
2. `guides.html`
3. `problems.html`
4. `reviews.html`
5. `cleaning.html`
6. `headliner-guide.html`
7. `videos.html`
8. `forum.html`
9. `deals.html`
10. `about.html`

## Before a real launch
- Replace Amazon search URLs with your approved affiliate deep links.
- Verify all product/price/deal claims.
- Replace YouTube search links with your approved videos/channels.
- Connect the newsletter and contact forms to a real provider.
- Replace the local-only demo forum with Supabase/Firebase/Discourse or another shared backend.
- Review your privacy, cookie, affiliate-disclosure and terms requirements for the programs/jurisdictions you use.

No build step or framework is required.
