# AutoInteriorHelp.com — GitHub Pages Demo

This folder is ready to upload directly to the root of a GitHub repository and publish with GitHub Pages.

## Included
- 10 fully linked content pages
- Exact supplied AutoInteriorHelp.com logo artwork in the site header/footer
- Responsive desktop/mobile layout
- Guides, problem library, product-review/affiliate sections, approved-video library, forum demo, deals, cleaning hub, long-form guide, and About/Contact page
- Client-side search/filter interactions
- Demo newsletter, forum, and contact interactions
- robots.txt, sitemap.xml, favicon, and 404 page

## Before production
1. Replace demo retailer/search URLs with your approved affiliate links and required network disclosures.
2. Replace demo product prices/ratings with current verified data.
3. Replace YouTube search links with the exact videos/channels you approve.
4. Connect the contact/newsletter/forum forms to real services if you want submissions stored or emailed.
5. Change the canonical domain in `sitemap.xml` if needed.

## GitHub Pages
Upload everything in this folder to the repository root, then enable Pages from the repository settings using the main branch/root folder.
